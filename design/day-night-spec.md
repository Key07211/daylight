# Daylight · 界面与动效

Daylight 是 Windows 桌面任务清单。原始可编辑 [Figma v1 设计稿](https://www.figma.com/design/UHEyr1qqi1WspOuH8QJVvP) 记录了最初的布局探索，尚未同步后续所有变化；当前行为以应用实装为准。

[使用手册](../docs/USER_GUIDE.md)包含完整操作说明。[产品演示](../docs/demo.html)使用独立示例数据，下载仓库后可离线打开。公开演示媒体位于 `docs/media/`，不包含个人任务。

## 界面与材质

三栏结构分别承载导航、任务和今日概览。玻璃表面使用统一的半透明底色、背景模糊、细边缘反光和轻微阴影。任务标题约 17 px，导航约 16 px。低对比装饰位于文字和控件后方，不截获点击。

日光使用米白、浅鼠尾草绿和暖金色，搭配向日葵、程序化玻璃丝带及随时间变化的天空；夜晚使用深蓝色、银河、月晕与细线悬挂星星。鼠标柔光限制在小范围。语言与玻璃偏好保存在本机，手动主题选择仅在当前窗口会话中临时生效。

## 时间与天气

主题使用电脑系统时间和时区：07:00 进入日光，19:00 进入夜晚。天气城市与 VPN 出口时区不改变这一规则。手动主题保留到下一次 07:00／19:00 边界或完整退出；收起到托盘、恢复和同一窗口刷新会保留选择，跨午夜不单独重置。启动时不再使用旧版长期保存的主题覆盖值。

实时天气支持自动识别城市和手动搜索修正。云量与雨雪取自天气城市，太阳位置和界面时钟采用系统时区。城市与系统时区一致且数据可用时使用当天日出日落；否则使用本地 06:00–18:00 的估算轨迹并标明估算。晨光、黄昏、晚霞及云雨共同调整环境光，夜间云雨会减弱月亮和星星亮度。

天气效果预览只改变视觉，不影响截止时间、提醒与实际主题规则。预览在当前窗口会话内保留，完整退出后恢复实时天气；手动城市选择仍然保存。网络不可用时显示缓存或不可用状态，本地任务仍可操作。

## 开场动画

首次显示主窗口时，应用根据当前系统时间和可用天气播放约四秒开场。日间太阳沿轨迹移动到当前时间位置，下方的向日葵回应光照；夜间月亮逐渐亮起，悬星错落落下，搭配银河与音符。雨天叠加雨窗、不同形状的水珠和微光。

开场提供「跳过动画」和 Escape 退出。播放时主界面暂不接受操作，结束后恢复焦点；隐藏窗口会结束正在播放的开场，恢复托盘窗口或刷新页面不重新播放。设置中可手动重播。关闭动态装饰或系统请求减少动态效果时直接进入清单；强制颜色模式减少不必要装饰。

## 雨与向日葵

水珠具有不同的透明度、非对称轮廓、高光方向和折射色调。静态水珠缓慢凝聚，滑动水珠沿玻璃表面的实际高度抵达底边，随后压扁、横向汇入边框水痕并消失。拖尾、水滴和边缘汇流共享时间线。

全屏雨场包含不同深度的雨线、短暂的落地水冠、抛物线飞溅水珠和扩散涟漪。粒子数量、绘制帧率与像素倍率均有上限；隐藏窗口时暂停环境动画。

日间向日葵采用不同节奏：雨滴触碰花瓣，花瓣下压后花盘回弹，茎部弯曲并逐渐复原。反应强度随雨量调整，品牌中的小向日葵保持静态。

## 交互与可访问性

- 整窗日夜转换采用约 700 ms 渐变，快速连续切换保留最后选择。
- 按钮和栏目有轻微悬停、按压反馈。导航内容平滑呈现，轮询更新不重复播放入场。
- 筛选和 Codex 字段平滑展开、收起并保留草稿；收起内容不可获得焦点。
- 弹窗有短暂进入、退出过渡。取消、Escape 和遮罩关闭共享行为；请求处理中阻止重复提交及关闭。
- 点击未完成任务圆圈先弹出确认。确认后提交一次；取消保留待办状态，并将焦点返回触发控件。恢复已完成任务直接生效。
- 设置提供玻璃通透度、背景模糊、高光强度与动态开关；减少动态偏好同时生效。
- 装饰不参与键盘导航，强制颜色模式优先保留文字与控件的可辨识度。

## Codex 与 Windows 发行

安装版支持连接本机 Codex，通过 MCP 管理任务，并通过本地调度启动 Codex CLI 作业。连接检查只验证握手、工具与服务状态，不创建测试任务或调用模型。源码连接迁移的范围及配置备份见 [MCP 与 Codex 指南](../docs/MCP_GUIDE.md)。

Windows x64 提供安装包和免安装包。当前版本、下载、校验和与验证方式见[项目首页](../README.md)及对应发行说明；测试覆盖和数量以该版本实际执行结果为准。
